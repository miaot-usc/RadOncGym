# RadOncGym

Radiotherapy dose-mimicking optimization environment.

```bash
python -m pip install -e .
```

Requires Python 3.10+. Live planning requires external [OpenKBP-Opt](https://github.com/ababier/open-kbp-opt) data and a licensed Gurobi installation.
